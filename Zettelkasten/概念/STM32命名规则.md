### 📌 命名结构图解

`STM32` + `[系列]` + `[子系列]` + `[引脚数]` + `[闪存容量]` + `[封装类型]` + `[温度范围]`

#### 1. **STM32**：品牌与架构

- **含义**：意法半导体（STMicroelectronics）推出的基于 **ARM Cortex-M** 内核的 **32 位** 微控制器。
- **注意**：所有 STM32 芯片都以这三个字符开头。

#### 2. **系列字母 (Series)**：产品定位

这是型号中最重要的字母，决定了芯片的**内核架构**和**主要应用场景**。

| 字母 | 系列名称 | 内核架构 | 特点与应用 |
|------|----------|----------|-----------|
| **F** | **Mainstream (主流)** | M0, M3, M4, M7 | **最常用**。性价比高，资料多。适合通用控制、电机、工业。 |
| **L** | **Low-power (低功耗)** | M0+, M3, M4 | 极致省电，支持多种休眠模式。适合电池供电设备（手表、传感器）。 |
| **H** | **High-performance (高性能)** | M7 | 主频极高 (400MHz+)，带双精度 FPU、GPU。适合高端 HMI、音频、AI。 |
| **G** | **General Purpose (新通用)** | M0+, M33 | F 系列的现代继任者，能效比更高，集成更多模拟外设。 |
| **U** | **Ultra-low-power** | M0+, M33 | 比 L 系列更极致的低功耗，基于 Cortex-M33。 |
| **W** | **Wireless (无线)** | M0+, M4 | 集成蓝牙、Wi-Fi、Zigbee 等射频功能。 |
| **MP** | **Microprocessor** | A7, A35 | 运行 Linux 的应用处理器（严格来说不算 MCU，但属 STM32 家族）。 |

#### 3. **子系列数字 (Sub-series)**：具体型号等级

紧跟在系列字母后的 3 位数字，代表该系列下的具体细分型号，通常暗示了**外设丰富度**和**性能等级**。

- **以 F1 系列为例**：
  - `101`：基本型 (Access)，外设较少。
  - `102`：USB 基本型。
  - `103`：**增强型 (Performance)**，最经典，外设全（如 STM32F**103**）。
  - `105/107`：互联型 (Connectivity)，带以太网、CAN 等。
- **以 F4 系列为例**：
  - `401`：入门级。
  - `405/407`：标准高性能（如 STM32F**407**）。
  - `427/437`：带更大内存和 TFT 控制器。

#### 4. **引脚数 (Pin Count)**：封装引脚数量

用**单个字母**表示芯片有多少个引脚，直接决定了可用的 GPIO 数量。

| 字母 | 引脚数 | 常见封装 |
|------|--------|---------|
| **T** | 36 脚 | LQFP32 (实际 36 脚位，常用 32 脚定义) |
| **C** | **48 脚** | LQFP48 (最常用，如 C8T6) |
| **R** | 64 脚 | LQFP64 |
| **V** | **100 脚** | LQFP100 (如 VGT6) |
| **Z** | 144 脚 | LQFP144 |
| **I** | 176 脚 | LQFP176 |
| **B** | 208 脚 | LQFP208 |

#### 5. **闪存容量 (Flash Memory)**：程序存储空间

用**单个字符**表示内置 Flash 的大小（单位：KB 或 MB）。

| 字符 | 容量 | 备注 |
|------|------|------|
| **4** | 16 KB | 小容量 |
| **6** | 32 KB | 小容量 (如 C**6**T6) |
| **8** | **64 KB** | 中容量 (如 C**8**T6) |
| **B** | **128 KB** | 中容量 (常用) |
| **C** | 256 KB | |
| **D** | 384 KB | |
| **E** | 512 KB | |
| **F** | 768 KB | |
| **G** | **1 MB** | 大容量 (如 V**G**T6) |
| **H** | 1.5 MB | |
| **I** | 2 MB | |

#### 6. **封装类型 (Package)**：物理外壳形式

表示芯片的物理封装形状。

| 字母 | 封装类型 | 描述 |
|------|----------|------|
| **T** | **[[LQFP]][[TQFP]]** | 薄型四方扁平封装 (最常用，引脚在四周) |
| **U** | UFQFPN | 超薄四方扁平无引脚封装 |
| **Y** | WLCSP | 晶圆级芯片尺寸封装 (极小，用于手机) |
| **S** | SOIC | 小外形集成电路 (仅用于少量低引脚芯片) |
| **H** | [[BGA]] | 球栅阵列封装 (用于 H7 等高端大引脚芯片) |

#### 7. **温度范围 (Temperature)**：工作环境温度

最后一位数字，代表芯片能正常工作的温度范围。

| 数字 | 温度范围 | 应用场景 |
|------|----------|---------|
| **6** | **-40°C ~ +85°C** | **工业级** (最常用，绝大多数开发板都是这个) |
| **7** | -40°C ~ +105°C | 扩展工业级 |
| **8** | -40°C ~ +125°C | 车规级/高温级 |
| **3** | 0°C ~ +70°C | 商业级 (现已较少见) |
