# 初等函数（复变函数）

**初等函数**是复变函数论中的基础概念，指由常数、复变量 $z$ 以及四则运算和复合运算有限次结合而成的函数。复变函数中的初等函数是实数域中初等函数的推广，定义方式尽可能保持一致。

## 一、定义与性质

复变初等函数主要从以下方面讨论：
- **定义域** — 使函数有意义的复数集合
- **运算法则** — 四则运算与复合运算
- **连续性** — 函数在定义域内的连续性质
- **解析性** — 函数是否可导（解析）
- **单值性** — 是否为单值函数
- **映射关系** — 复平面上点的对应关系

## 二、指数函数 $e^z$

指数函数的虚数部分通过**欧拉公式**来定义，其余初等函数均通过指数函数定义：

$$e^z = e^{x+iy} = e^x (\cos y + i \sin y)$$

**基本性质**：
- $e^z$ 是**单值函数**
- 除无穷远点外均有定义
- $e^z \neq 0$（实部永远大于0）
- 乘法运算与实数域上一致：$e^{z_1} \cdot e^{z_2} = e^{z_1+z_2}$
- **周期函数**，周期为 $2k\pi i$（$k$ 为整数）
- 由实部得模，由虚部得辐角

## 三、对数函数 $\ln z$

对数函数定义为指数函数的**反函数**，记为 $\text{Ln}\,z$：

$$\text{Ln}\,z = \ln|z| + i \arg z$$

**重要性质**：
- 由于 $\arg z$ 的多值性，$\text{Ln}\,z$ 为**多值函数**
- 在原点无定义，定义域为 $z \neq 0$
- $\text{Ln}\,z^n \neq n \text{Ln}\,z$（多值性导致）
- 在除去原点及负实轴的平面内解析
- **关键结论**：在复变函数中，**负实数也可以求对数**

主值分支（Principal branch）：$\ln z = \ln|z| + i \text{Arg}\,z$，其中 $-\pi < \text{Arg}\,z \leq \pi$

## 四、幂函数 $z^\alpha$

幂函数通过指数函数定义：

$$z^\alpha = e^{\alpha \text{Ln}\,z}$$

- 当 $\alpha$ 为整数时，$z^\alpha$ 为单值函数
- 当 $\alpha$ 为有理数或无理数时，$z^\alpha$ 为多值函数

## 五、三角函数

三角函数通过指数函数定义：

$$\sin z = \frac{e^{iz} - e^{-iz}}{2i}, \quad \cos z = \frac{e^{iz} + e^{-iz}}{2}$$

- $\sin z$ 和 $\cos z$ 均为**整函数**（在全平面解析）
- 周期为 $2\pi$
- **注意**：复数域中 $|\sin z|$ 和 $|\cos z|$ **可以大于1**（与实数域不同）

## 六、反三角函数

反三角函数通过对数函数定义：

$$\arcsin z = -i \text{Ln}(iz + \sqrt{1-z^2})$$

$$\arccos z = -i \text{Ln}(z + \sqrt{z^2-1})$$

- 均为多值函数
- 需在复平面上选择适当的分支割线

## 七、双曲函数

双曲函数与三角函数有类似的指数定义：

$$\sinh z = \frac{e^z - e^{-z}}{2}, \quad \cosh z = \frac{e^z + e^{-z}}{2}$$

**与三角函数的关系**：
$$\sin(iz) = i\sinh z, \quad \cos(iz) = \cosh z$$
