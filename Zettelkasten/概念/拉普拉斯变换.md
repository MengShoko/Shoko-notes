# 拉普拉斯变换

**拉普拉斯变换**是傅里叶变换的推广，用于分析更广泛的信号和系统。

## 一、定义

### 双边拉普拉斯变换
$$X(s) = \int_{-\infty}^{+\infty} x(t) e^{-st} dt, \quad s = \sigma + j\omega$$

### 单边拉普拉斯变换
$$X(s) = \int_{0^-}^{+\infty} x(t) e^{-st} dt$$

## 二、与傅里叶变换的关系

当 $s = j\omega$（即 $\sigma = 0$）时，拉普拉斯变换退化为傅里叶变换。

## 三、收敛域（ROC）

拉普拉斯变换的收敛域是使积分收敛的 $s$ 平面区域：
- 右边信号：ROC 为某竖线右侧
- 左边信号：ROC 为某竖线左侧
- 双边信号：ROC 为带状区域

## 四、主要性质

| 性质 | 时域操作 | 复频域操作 |
|------|----------|-----------|
| 线性 | $ax_1(t) + bx_2(t)$ | $aX_1(s) + bX_2(s)$ |
| 时移 | $x(t-t_0)u(t-t_0)$ | $e^{-s t_0}X(s)$ |
| 微分 | $\frac{dx(t)}{dt}$ | $sX(s) - x(0^-)$ |
| 积分 | $\int_{0^-}^{t} x(\tau)d\tau$ | $\frac{X(s)}{s}$ |
| 卷积 | $x_1(t)*x_2(t)$ | $X_1(s) \cdot X_2(s)$ |

## 五、应用

1. **系统分析**：系统函数 $H(s) = \frac{Y(s)}{X(s)}$
2. **微分方程求解**：将微分方程转化为代数方程
3. **稳定性分析**：通过极点位置判断系统稳定性
4. **电路分析**：复频域电路模型
