# 平面的矩阵表示

## 基本定义

三维空间中，一个平面通常用三元一次方程表示：

$$Ax + By + Cz + D = 0$$

可以写成矩阵形式：

$$\begin{bmatrix} A & B & C \end{bmatrix} \begin{bmatrix} x \\ y \\ z \end{bmatrix} + D = 0$$

或记作平面法向量 $\mathbf{n} = (A, B, C)$ 与空间点 $\mathbf{p} = (x, y, z)^T$ 的点积满足：

$$\mathbf{n}^T \mathbf{p} + D = 0$$

## 齐次坐标表示

在齐次坐标下，平面可表示为四维列向量 $\mathbf{\pi} = (A, B, C, D)^T$，空间点表示为 $\mathbf{p} = (x, y, z, 1)^T$，则平面方程简化为：

$$\mathbf{\pi}^T \mathbf{p} = 0$$

## 与直线的关系

- 平面与平面的交线是一条**直线**（见 [[直线的矩阵表示]]）
- 点与平面的关系：点代入平面方程，结果为 0 则在平面上，否则不在

## 应用

- 计算机图形学中的裁剪、可见性判断
- 机器人学中描述机械臂工作空间边界
- 计算几何中的点面距离：$d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$
