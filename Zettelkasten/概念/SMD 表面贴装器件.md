# SMD 表面贴装器件

**SMD** (Surface Mount Device) 是现代电子工业的绝对主流，代表电子元器件从"插孔式"向"贴装式"的革命性转变。

## 核心概念

- **SMD (器件)**：具体的元器件本身（电阻、电容、芯片）
- **SMT (技术)**：**Surface Mount Technology**（表面贴装技术），是安装工艺过程
- **对应关系**：
  - 传统工艺：THT (通孔插装技术) ↔ DIP (双列直插封装)
  - 现代工艺：**SMT** ↔ **SMD**

## 主要特点

| 特性 | 描述 |
|------|------|
| **体积小、重量轻** | 传统插件元件体积的 1/10 到 1/3，重量减轻 60%-90% |
| **高密度组装** | 无需打孔，可双面贴装，大幅提高集成度 |
| **高频性能好** | 引脚极短甚至无引脚，寄生参数小 |
| **适合自动化生产** | 高速贴片机操作，生产速度快 |
| **成本降低** | 减少PCB钻孔工序，整体系统成本更低 |

## 常见封装形式

### 无源元件（电阻、电容、电感）

- **英制代码**：数字表示尺寸（长×宽，单位 0.01 英寸）
  - **0402** (1.0mm × 0.5mm)：极小，常用于手机
  - **0603** (1.6mm × 0.8mm)：最通用
  - **0805** (2.0mm × 1.25mm)：功率稍大场合
  - **1206** (3.2mm × 1.6mm)：易于手工操作

### 有源元件（晶体管、IC芯片）

- **SOP / SOIC**：两侧有引脚，DIP缩小版
- **QFP**：四侧都有引脚，常用于微控制器
- **QFN / DFN**：无引脚，底部有散热焊盘
- **BGA**：底部锡球阵列，用于CPU/GPU，密度最高

## SMD vs. DIP

| 对比维度 | SMD | DIP |
|---------|-----|-----|
| **安装方式** | 贴在PCB表面，无需打孔 | 引脚穿过PCB孔 |
| **体积/重量** | 极小、极轻 | 较大、较重 |
| **生产方式** | 全自动高速贴片机 | 需插件机或人工 |
| **高频性能** | 优 | 较差 |
| **手工焊接** | 较难 | 容易 |
| **维修更换** | 较难 | 容易 |
| **主要应用** | 手机、电脑、消费电子 | 教学、原型、大功率 |

## 应用场景

- **消费电子**：智能手机、平板、智能手表（几乎100% SMD）
- **计算机硬件**：主板、显卡、内存
- **汽车电子**：ECU控制单元、传感器
- **医疗设备**：便携式监护仪
- **航空航天**：卫星、导弹制导

## 挑战与趋势

- **微型化极限**：0201、01005封装对精度要求极高
- **散热问题**：元件密集，依赖PCB铜箔散热
- **维修难度**：焊接0402或BGA需要专业工具
