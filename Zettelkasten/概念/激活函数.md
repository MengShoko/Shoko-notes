# 激活函数

## 定义
激活函数是神经网络中引入非线性的关键组件，决定神经元是否被激活以及如何传递信号。

## 常见激活函数

### Sigmoid
$$\sigma(x) = \frac{1}{1+e^{-x}}$$
- 输出范围：(0, 1)
- 问题：梯度消失、输出非零中心

### Tanh
$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$
- 输出范围：(-1, 1)
- 比Sigmoid好，输出零中心

### ReLU
$$\text{ReLU}(x) = \max(0, x)$$
- 计算简单，梯度不消失
- 问题：Dead ReLU（神经元死亡）

### Leaky ReLU
$$\text{Leaky ReLU}(x) = \max(\alpha x, x), \quad \alpha \approx 0.01$$
- 解决Dead ReLU问题

### Softmax
$$\text{Softmax}(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}}$$
- 多分类输出层常用
- 输出概率分布

## 选择建议

| 场景 | 推荐激活函数 |
|------|-------------|
| 隐藏层 | ReLU / Leaky ReLU |
| 二分类输出 | Sigmoid |
| 多分类输出 | Softmax |
| 回归输出 | Linear |
