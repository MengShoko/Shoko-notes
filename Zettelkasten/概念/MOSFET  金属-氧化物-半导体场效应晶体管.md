# MOSFET 金属-氧化物-半导体场效应晶体管

**Metal-Oxide-Semiconductor Field-Effect Transistor**，==简称MOS管==，是目前应用最广泛的半导体器件，构成了从微处理器（CPU/GPU）到电源管理芯片的核心。

## 核心结构与名称由来

- **结构**：由**金属**（栅极 Gate）、**氧化物**（绝缘层，SiO₂）、**半导体**（源极 Source/漏极 Drain）三层组成
- **本质**：**电压控制型**器件，通过栅极电压控制源漏之间电流
- **输入阻抗极高**：栅极与沟道之间有绝缘层，理论上无电流流入

## 工作原理（N沟道增强型）

MOSFET 的核心是**电容效应**：

1. **截止状态 (V_GS = 0)**：源漏之间是两个背靠背的 PN 结，电流无法通过
2. **导通状态 (V_GS > V_th)**：
   - 栅极施加正向电压超过**阈值电压 (V_th)**
   - P 型半导体表面感应出负电荷（电子）
   - 形成 **N 型导电沟道**（反型层），连接源漏
   - V_GS 越高，沟道越宽，电阻越小

## 主要分类

| 分类维度 | 类型 | 特点与应用 |
|---------|------|-----------|
| **沟道极性** | **N-MOS** | 电子导电，迁移率高，速度块，导通电阻小。**最常用** |
| | **P-MOS** | 空穴导电，迁移率低。常用于高端开关或互补电路 |
| **工作模式** | **增强型** | V_GS=0 时截止，需加电压才导通。**主流** |
| | **耗尽型** | V_GS=0 时已导通，需反向电压才截止 |

## MOSFET vs. IGBT

| 特性 | MOSFET | IGBT |
|------|--------|------|
| **驱动机制** | 多数载流子导电（单极型） | 多数+少数载流子（复合双极型） |
| **开关速度** | **极快**（ns级，MHz） | 较慢（μs级，kHz级） |
| **导通损耗** | 低压下极低；高压下急剧增加 | 高压下导通压降低且稳定 |
| **耐压能力** | 通常 < 1000V | 轻松达到 1700V-6500V+ |
| **最佳应用** | **低压高频**（< 200V, > 100kHz） | **高压大电流低频**（> 600V, < 20kHz） |
| **典型场景** | CPU供电、DC-DC转换器 | 高铁牵引、光伏逆变器、电动车 |

> **简单记忆**：
> - **低压高频选 MOSFET**
> - **高压大电流选 IGBT**
> - **中间地带用 SiC MOSFET**

## 关键应用领域

1. **数字集成电路 (CPU/Memory)**：CMOS技术是低功耗数字电路基础
2. **电源管理**：DC-DC转换器、同步整流
3. **电机驱动**：H桥驱动
4. **保护电路**：防反接、过流保护

## 未来趋势：宽禁带半导体

- **SiC MOSFET**：耐高压、耐高温、损耗极低，用于高端电动车
- **GaN**：开关速度极快，用于手机快充头
