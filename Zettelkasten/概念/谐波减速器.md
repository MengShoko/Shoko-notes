# 谐波减速器（Harmonic Drive）

学名**应变波齿轮**（Strain Wave Gearing），是一种利用金属弹性形变原理来实现**高减速比、高精度传动**的机械装置。

## 核心结构：三大件

### 1. 波发生器（Wave Generator）
- **角色**：输入端（主动件）
- **构造**：椭圆形凸轮 + 薄壁柔性轴承
- **作用**：装入柔轮后，迫使柔轮从圆形变更为椭圆形

### 2. 柔轮（Flexspline）
- **角色**：输出端（从动件）
- **构造**：薄壁圆柱形金属环，外圈带齿轮，具有弹性，可发生可控变形
- **特点**：齿数比刚轮**少 2 个齿**（减速的关键）

### 3. 刚轮（Circular Spline）
- **角色**：固定端（通常固定在壳体上，不转动）
- **构造**：刚性内齿轮
- **特点**：齿数比柔轮**多 2 个齿**

## 工作原理

### 1. 变形
波发生器（椭圆）插入柔轮（圆）内部，将柔轮撑成椭圆形。

### 2. 啮合
- 在椭圆的**长轴两端**：柔轮齿与刚轮齿完全啮合
- 在椭圆的**短轴两端**：柔轮齿与刚轮齿完全分离
- 其余部分处于过渡态

### 3. 转动与减速
柔轮比刚轮少 2 个齿，波发生器每转一圈，柔轮相对刚轮**反向转动 2 个齿**。

- **输入轴**（波发生器）：高速旋转
- **输出轴**（柔轮）：低速、大扭矩地反向旋转

## 主要特点

| 特性 | 说明 |
|------|------|
| 减速比大 | 可达 50:1 ~ 320:1，单级即可实现大减速比 |
| 精度高 | 回程间隙小，定位精度可达弧分级 |
| 结构紧凑 | 同功率下体积小、重量轻 |
| 传动平稳 | 啮合齿数多，运转平稳，噪音低 |
| 效率较高 | 单级效率约 70%~90% |
