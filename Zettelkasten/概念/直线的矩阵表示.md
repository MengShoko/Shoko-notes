# 直线的矩阵表示

## 基本定义

平面中的直线可以用一个列向量（矩阵）来表示：

$$\mathbf{l} = \begin{bmatrix} a \\ b \\ c \end{bmatrix}$$

其中直线方程为 $ax + by + c = 0$，向量 $(a, b)$ 与直线的法向量相同（数值与单位向量相同）。

## 点到直线的投影距离

求平面中某个点 $\mathbf{p} = (x_0, y_0)^T$ 投影到直线 $\mathbf{l}$ 上，点到原点的距离就是直线矩阵的转置乘点矩阵：

$$d = \mathbf{l}^T \mathbf{p} = ax_0 + by_0$$

归一化后（直线为单位向量）即为点到直线的垂直距离。

## 齐次坐标表示

在齐次坐标下，直线可表示为三维向量 $\mathbf{l} = (a, b, c)^T$，点表示为 $\mathbf{p} = (x, y, 1)^T$，则直线方程为：

$$\mathbf{l}^T \mathbf{p} = 0$$
