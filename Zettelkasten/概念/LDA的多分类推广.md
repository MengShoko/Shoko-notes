# LDA 的多分类推广

线性判别分析（LDA）原本针对二分类问题，可扩展至多分类场景。

## 核心思想

**全局散度矩阵** $S_t$ 是协方差矩阵的推广，由以下两部分组成：

$$S_t = S_w + S_b$$

- $S_w$：**类内散度矩阵**（within-class scatter matrix），分子，衡量同类样本的紧凑性
- $S_b$：**类间散度矩阵**（between-class scatter matrix），分母，衡量不同类中心的分散程度

## 多分类 LDA 的目标

LDA 的目标是找到一个投影方向（或子空间），使得：
- **类内散度尽可能小**（同类样本投影后尽可能接近）
- **类间散度尽可能大**（不同类中心的投影尽可能分离）

即最大化广义瑞利商（generalized Rayleigh quotient）：

$$J(w) = \frac{w^T S_b w}{w^T S_w w}$$

## 多分类求解

对于 $C$ 类问题，最优投影维度最多为 $\min(C-1, d)$ 维（$d$ 为原始特征维度）。

通过求解广义特征值问题：

$$S_b w = \lambda S_w w$$

取前 $k$ 个最大特征值对应的特征向量构成投影矩阵。

## 与 [[协方差矩阵]] 的关系

类内散度矩阵 $S_w$ 可以看作是各类**协方差矩阵的加权和**，反映了样本在各类内部的离散程度。
