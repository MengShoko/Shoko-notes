# 单位阶跃信号

**单位阶跃信号** $u(t)$ 是最基本的奇异信号之一。

## 一、定义

$$u(t) = \begin{cases} 0, & t < 0 \\ 1, & t > 0 \end{cases}$$

在跳变点 $t=0$ 处可不予定义，或规定 $u(0) = 1/2$。

## 二、性质

### 与冲激信号的关系
$$\delta(t) = \frac{du(t)}{dt}$$
$$u(t) = \int_{-\infty}^{t} \delta(\tau) d\tau$$

### 平移
$$u(t-t_0)$$ 表示在 $t_0$ 时刻跳变的阶跃信号。

## 三、应用

1. 表示信号的开关特性
2. 构造有限持续时间信号：$x(t)[u(t-t_1) - u(t-t_2)]$
3. LTI 系统分析的起始条件
