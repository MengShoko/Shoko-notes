## 一、PWM基本概念

**脉冲宽度调制（PWM，Pulse Width Modulation）** 是利用微处理器的数字输出来对模拟电路进行控制的一种有效技术。

### 核心参数

| 参数 | 定义 | 单位 |
|------|------|------|
| **频率** | 1秒内信号周期次数 | Hz |
| **周期** | T = 1/f | s/ms |
| **占空比** | 高电平时间与周期时间的比例 | % |

### 示例计算

- 50Hz → 周期 = 20ms
- 占空比80% → 高电平16ms，低电平4ms

## 二、PWM原理

PWM通过改变**占空比**来调节输出的**平均电压**：

$$V_{avg} = V_{cc} \times \frac{T_{on}}{T}$$

- 占空比50% → 平均电压 = 2.5V（5V系统）
- 占空比75% → 平均电压 = 3.75V（5V系统）

## 三、应用场景

### 1. LED调光（呼吸灯）

- 人眼对80Hz以上无闪烁感
- 占空比越大，LED越亮
- 通过改变占空比实现亮度调节

### 2. 电机转速控制

- 占空比越大，电机转速越快
- 正常频率：6-16kHz
- 频率太低会导致运动不稳定

### 3. 舵机控制

- 固定频率50Hz（周期20ms）
- 高电平0.5ms-2.5ms控制角度
- 对应关系：

| 高电平时间 | 舵机角度 |
|-----------|---------|
| 0.5ms | 0° |
| 1.0ms | 45° |
| 1.5ms | 90° |
| 2.0ms | 135° |
| 2.5ms | 180° |
