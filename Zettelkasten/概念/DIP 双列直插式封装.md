# DIP 双列直插式封装

**Dual In-line Package**，这是一种经典的芯片封装形式，其特点是芯片两侧有平行的引脚，需要垂直插入电路板的通孔中进行焊接或安装在插座上。尽管现代电子设备多采用更小的表面贴装（[[SMD 表面贴装器件]]）技术，但 DIP 封装因其独特的优势，在特定领域依然不可或缺。

## 核心特征

- **外观结构**：封装体通常为长方形（塑料或陶瓷材质），**两排引脚平行分布**在长边两侧。
- **引脚间距**：标准间距为 **0.1 英寸（2.54 mm）**。这是电子工程中最经典的尺寸标准。
- **安装方式**：**通孔插装技术 (THT)**。引脚穿过电路板上的孔，在背面进行焊接，或者插入专用的 IC 插座（Socket）中。
- **命名规则**：通常以 **DIP + 引脚数** 命名。
  - 例如：**DIP-8**（8 脚）、**DIP-14**（14 脚）、**DIP-40**（40 脚，如早期的 8051 单片机）。
  - 引脚计数：面对芯片正面的缺口（或圆点标记），**左下角为第 1 脚**，逆时针方向依次计数。

## 主要优缺点

| 优点 | 缺点 |
|------|------|
| **易于手工操作**：引脚间距大，非常适合**面包板 (Breadboard)** 原型开发、教学实验和手工焊接。 | **体积大**：占用 PCB 面积大，无法实现高密度集成，不适合手机等便携设备。 |
| **可更换性强**：配合 IC 插座使用，芯片损坏后可直接拔插更换，无需拆焊。 | **电气性能受限**：引脚较长，导致寄生电感和电容较大，不适合高频高速信号传输。 |
| **机械强度高**：通孔焊接比表面贴装更牢固，耐振动，适合工业环境。 | **自动化成本高**：在现代大规模 SMT 生产线中，DIP 需要额外的插件工序（或人工），效率较低。 |
| **散热较好**：相比某些微型封装，其较大的体积有利于自然散热。 | |

## 应用场景

1. **教育与原型开发**：大学生电子竞赛、Arduino 模块、树莓派扩展板等。
2. **工业控制与汽车电子**：对可靠性要求高、不需要极致小型化的场合。
3. **维修与替换**：老旧设备的维护。
4. **特定元器件**：555 定时器（DIP-8）、运算放大器（LM358, LM741）、光耦合器（PC817）、经典单片机（AT89C51, ATmega328P）。

## 历史地位

- **起源**：由快捷半导体（Fairchild Semiconductor）的 Bryant Buck Rogers 于 **1964 年**发明。
- **黄金时代**：20 世纪 70 年代至 90 年代，是微处理器、存储器和逻辑芯片的标准封装。
- **现状**：随着电子产品向"轻、薄、短、小"发展，表面贴装技术（SMT）成为主流。
