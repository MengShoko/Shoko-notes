**BGA** 是 **Ball Grid Array** 的缩写，中文称为**球栅阵列封装**。

它是现代高性能芯片（如电脑 CPU、GPU、手机处理器以及高端 STM32 如 H7/F7 系列）最主流的封装形式。你之前问的 **TFBGA** 其实就是 BGA 的一种特定类型（薄型、细间距）。

---

### 1. 核心概念：什么是 BGA？

- **传统封装 (如 LQFP)**：引脚像"腿"一样从芯片四周伸出来，焊接在 PCB 表面。
- **BGA 封装**：**没有外伸的引脚**。
- 芯片底部是一个网格状排列的**焊锡球** (Solder Balls)。
- 焊接时，芯片直接"坐"在 PCB 对应的焊盘上，加热后锡球熔化，形成电气连接和机械固定。
- 看起来就像芯片底部长满了"小痘痘"。

### 2. BGA 的核心优势

为什么高端芯片都要用 BGA？

| 优势 | 解释 |
|------|------|
| **超高引脚密度** | LQFP 受限于芯片周长，引脚多了就没地方排了。BGA 利用**整个底部面积**排列锡球，轻松实现 200~1000+ 个连接点。 |
| **卓越的电气性能** | 锡球连接路径极短，寄生电感和电容非常小。这对于**高速信号**（如 DDR 内存接口、高速 USB、以太网、MIPI 摄像头）至关重要。 |
| **优异的散热性** | 芯片产生的热量可以直接通过底部的锡球传导到 PCB 的大面积铜箔上，散热效率远高于四周引脚。 |
| **体积更小** | 去掉了四周伸出的引脚框架，封装尺寸可以做得非常紧凑，适合手机、手表等便携设备。 |
| **自对准效应** | 焊接时，熔化的锡球表面张力会自动将芯片拉回到正确的位置，即使贴片机稍微有点偏差也能自动修正。 |

### 3. BGA 的缺点与挑战

- **焊接难度极大**：**无法手工焊接**。必须使用精密的贴片机、钢网印刷锡膏，并通过回流焊炉进行焊接。
- **检测困难**：焊点在芯片底部，焊好后**肉眼看不见**。必须使用 **X 射线检测仪 (X-Ray)** 来检查是否有虚焊、连锡或气泡。
- **维修成本高**：一旦损坏，需要专业的返修台进行拆焊和植球（Reballing），普通维修店很难处理，通常直接更换整个主板或核心板。
- **PCB 设计要求高**：由于锡球排列密集，PCB 布线通常需要多层板（4 层以上），甚至需要使用**盲孔/埋孔**技术来引出中间的信号，增加了制板成本。

### 4. BGA 家族成员 (前缀含义)

BGA 是一个大类，根据厚度和间距不同，有很多变种，常在 STM32 型号中看到：

| 缩写 | 全称 | 特点 | 常见应用 |
|------|------|------|---------|
| **BGA** | Ball Grid Array | 标准球栅阵列，间距较大 (1.0mm, 1.27mm)。 | 早期 FPGA、部分老款 MCU。 |
| **TBGA** | **T**hin BGA | **薄型** BGA，厚度减小。 | 通用高性能芯片。 |
| **TFBGA** | **T**hin **F**ine-pitch BGA | **薄型 + 细间距** (0.5mm, 0.8mm)。 | **STM32 H7/F7 系列** (如 `STM32H743VIH6` 中的 `H` 封装)。 |
| **UFBGA** | **U**ltra **F**ine-pitch BGA | **超细间距** (0.4mm 或更小)，极致轻薄。 | 手机 SoC、超薄穿戴设备 MCU。 |
| **LFBGA** | **L**ow-profile **F**ine-pitch BGA | 低轮廓细间距，介于 TFBGA 和 UFBGA 之间。 | 高性能嵌入式系统。 |

### 5. 在 STM32 中的实际应用

回顾 [[STM32命名规则]]，封装代码通常在倒数第二位：

- **T** = LQFP (四方扁平，手工可焊，适合 F1/F4 中低端)。
- **H** = TFBGA (薄型细间距球栅，机器焊接，适合 **H7/F7** 高端)。
- **B** = UFBGA 或 LFBGA (更细间距，用于极致小型化)。

**例子**：

- `STM32F407VGT6` -> **T** (LQFP100)：适合学生开发板，手工能焊。
- `STM32H743VIH6` -> **H** (TFBGA100)：适合工业高端控制，必须机器贴片。
