# IGBT 绝缘栅双极型晶体管

**Insulated Gate Bipolar Transistor**，是一种复合全控型电压驱动式功率半导体器件。

## 核心结构与工作原理

- **结构**：IGBT 可以看作是一个由 MOSFET 驱动的厚基区 PNP 双极型晶体管
- **三个端子**：**栅极 (G)**、**集电极 (C)**、**发射极 (E)**
- **工作逻辑**：
  - **导通**：栅极施加正向电压时，内部 MOSFET 部分导通，为双极型部分提供基极电流，IGBT 导通
  - **关断**：栅极电压撤去或施加反向电压时，IGBT 迅速关断

## 主要应用领域

| 应用领域 | 具体作用 |
|---------|---------|
| **新能源汽车 (EV)** | 电机控制器核心器件，将电池 DC 转换为 AC 驱动电机，占成本约 5%-10% |
| **轨道交通** | 高铁、地铁牵引变流器，中国中车处于世界领先地位 |
| **智能电网/特高压** | 柔性直流输电 (HVDC)、STATCOM |
| **工业控制** | 变频器、伺服驱动器、UPS、感应加热 |
| **白色家电** | 变频空调、电磁炉 |

## 未来趋势：SiC (碳化硅) 的挑战

- **SiC 优势**：耐温更高、开关损耗更低、频率更高
- **现状**：在 800V 高压平台高端电动车上，SiC 正在逐步替代 IGBT
- **IGBT 的地位**：成本优势，750V 以下电压等级成熟度，未来长期市场主力
