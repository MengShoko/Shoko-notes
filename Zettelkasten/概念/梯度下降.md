# 梯度下降

## 定义
梯度下降是一种通过沿负梯度方向迭代更新参数来最小化损失函数的优化算法。

## 基本公式
$$\theta_{t+1} = \theta_t - \eta \nabla_\theta J(\theta_t)$$

| 符号 | 含义 |
|------|------|
| $\theta$ | 模型参数 |
| $\eta$ | 学习率 |
| $\nabla_\theta J$ | 损失函数梯度 |

## 三种变体

### 批量梯度下降（BGD）
- 使用全部数据计算梯度
- 稳定但慢
- 内存消耗大

### 随机梯度下降（SGD）
- 每次用一个样本更新
- 快但有噪声
- 可能震荡

### 小批量梯度下降（Mini-batch）
- 平衡速度与稳定性
- 最常用的方法
- batch_size通常取32、64、128

## 改进算法

| 算法 | 特点 |
|------|------|
| Momentum | 加速收敛，减少震荡 |
| AdaGrad | 自适应学习率 |
| RMSprop | 解决AdaGrad学习率衰减 |
| Adam | 结合Momentum和RMSprop，最常用 |

## 学习率调度
- 固定学习率
- 学习率衰减
- 自适应学习率（Adam等）
