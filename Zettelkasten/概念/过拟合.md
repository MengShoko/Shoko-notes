# 过拟合

## 定义
过拟合（Overfitting）是指模型在训练数据上表现很好，但在未见数据上表现很差的现象。

## 特征
- 训练误差远低于测试误差
- 模型记住了训练数据的噪声和细节
- 泛化能力差

## 原因
1. 模型复杂度过高
2. 训练数据太少
3. 训练时间过长
4. 数据含有噪声

## 解决方法

| 方法 | 原理 |
|------|------|
| 正则化 | 在损失函数中添加惩罚项 |
| Dropout | 随机丢弃部分神经元 |
| 数据增强 | 增加训练数据多样性 |
| 早停法 | 在验证集误差开始上升时停止 |
| 集成学习 | 多个模型平均降低方差 |
