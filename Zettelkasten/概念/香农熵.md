# 香农熵

## 定义
香农熵（Shannon Entropy）是信息论中的核心概念，用于衡量随机变量的不确定性或信息量。

## 公式

$$H(X) = -\sum_{i} P(x_i) \log P(x_i)$$

对于策略 $\pi$ 在状态 $s$ 下的熵：

$$H(\pi_\theta(\cdot|s)) = -\sum_a \pi_\theta(a|s) \log \pi_\theta(a|s)$$

## 公式拆解

| 符号 | 含义 |
|------|------|
| $P(a|s)$ | 在状态 $s$ 下选择动作 $a$ 的概率 |
| $\log P(a|s)$ | 对数概率（值为负） |
| $-\sum$ | 求和并取反，使结果为正 |

## 物理意义
- **熵越大** → 不确定性越高 → 策略越"随机"
- **熵越小** → 确定性越高 → 策略越"贪婪"
- **熵为0** → 完全确定（某个动作概率为1）

## 在强化学习中的应用
- **SAC（Soft Actor-Critic）**：通过最大化熵鼓励探索
- **熵正则化**：防止策略过早收敛到次优解
- **温度参数 α**：控制熵的重要性
