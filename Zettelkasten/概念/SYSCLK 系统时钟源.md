## 一、时钟源概述

**SYSCLK（System Clock）** 是STM32的系统时钟，可由以下时钟源选择：

## 二、三大时钟源

### 1. HSI（High Speed Internal）—— 高速内部时钟

| 属性 | 说明 |
|------|------|
| **来源** | 芯片内部RC振荡器 |
| **特点** | 启动快，精度低，受温度影响 |
| **频率** | F1系列 8MHz |
| **应用** | 上电初始化、低成本应用 |

### 2. HSE（High Speed External）—— 高速外部时钟

| 属性 | 说明 |
|------|------|
| **来源** | 外部晶振/陶瓷谐振器 |
| **特点** | 精度高，稳定性强 |
| **频率** | 常用 8MHz（4-16MHz支持） |
| **应用** | 高精度系统时钟基准、PLL输入源 |

### 3. PLLCLK —— 锁相环时钟

| 属性 | 说明 |
|------|------|
| **来源** | PLL倍频器（非独立时钟源） |
| **输入** | HSE、HSE/2 或 HSI/2 |
| **特点** | 倍频输出更高频率 |
| **最大频率** | F1系列 72MHz |
| **应用** | 系统全速运行 |

## 三、典型时钟配置

```
HSE 8MHz → PLL 9倍频 → PLLCLK 72MHz → SYSCLK
```

## 四、时钟树结构

- **主PLL**：由HSE/HSI提供，两个输出时钟
- **专用PLL（PLLI2S）**：用于I2S高品质音频
