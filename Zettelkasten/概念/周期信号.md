# 周期信号

**周期信号**是以一定时间间隔周而复始的信号。

## 一、定义

连续时间周期信号：$x(t) = x(t + T_0)$，$T_0$ 为周期。

离散时间周期信号：$x[n] = x[n + N]$，$N$ 为周期。

## 二、分类

- **简谐信号**：正弦/余弦信号，是最基本的周期信号
- **复杂周期信号**：除简谐信号外的所有周期信号

> **周期信号和非周期信号都是规则信号**

## 三、参数

- **基波频率** $f = 1/T_0$，单位 Hz
- **基波角频率** $\omega_0 = 2\pi f = 2\pi/T_0$，单位 rad/s

## 四、傅里叶级数

任何周期信号可分解为谐波信号的叠加：
$$x(t) = \sum_{n=-\infty}^{+\infty} a_n e^{jn\omega_0 t}$$
