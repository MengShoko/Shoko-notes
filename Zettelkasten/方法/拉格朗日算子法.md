# 拉格朗日算子法（拉格朗日乘子法）

解决**带约束的最优化问题**的核心数学工具。

## 基本原理

对于约束优化问题：

$$\min_{\mathbf{x}} f(\mathbf{x}) \quad \text{s.t.} \quad g_i(\mathbf{x}) = 0, \; h_j(\mathbf{x}) \leq 0$$

引入拉格朗日乘子 $\lambda_i, \mu_j$，构造拉格朗日函数：

$$\mathcal{L}(\mathbf{x}, \lambda, \mu) = f(\mathbf{x}) + \sum_i \lambda_i g_i(\mathbf{x}) + \sum_j \mu_j h_j(\mathbf{x})$$

## 求解步骤

1. 构造拉格朗日函数
2. 对 $\mathbf{x}$ 求偏导并令其为零
3. 结合约束条件求解方程组
4. 验证 KKT 条件（对于不等式约束）

## 在机器学习中的应用

### LDA 中的拉格朗日乘子法

[[线性判别分析|LDA]] 的目标是最大化广义瑞利商：

$$J(\mathbf{w}) = \frac{\mathbf{w}^T S_b \mathbf{w}}{\mathbf{w}^T S_w \mathbf{w}}$$

由于 $\mathbf{w}$ 的长度不影响结果（只方向起作用），通过拉格朗日乘子法引入约束，得到：

$$S_b \mathbf{w} = \lambda S_w \mathbf{w}$$

即广义特征值问题，从而解出最优投影方向 $\mathbf{w}$。
