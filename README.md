## 📝 文件存放规则

| 文件类型 | 存放位置 | 命名规则 |
|---------|---------|---------|
| 临时粘贴的截图/内容 | `00_Inbox/` | 日期+简述，如 `2026-08-20-flow-matching.png` |
| 正在学习的课程笔记 | `20_Areas/机器学习/` | 主题名，如 `梯度下降.md` |
| 单条知识点/概念 | `Zettelkasten/概念/` | 概念名，如 `过拟合.md` |
| 算法/方法笔记 | `Zettelkasten/方法/` | 方法名，如 `k折交叉验证.md` |
| 教材/书籍系统笔记 | `20_Areas/机器学习/周志华教材/` | 章节名 |
| 引用论文笔记 | `30_Resources/论文/` | 作者-年份-简称.md |
| PDF原文 | `Assets/PDFs/` | 文件名.pdf |
| 图片 | `Assets/Images/` | 文件名.png |

## 🔗 Zettelkasten 链接规则

1. **每条笔记至少链接 2 条其他笔记**
2. **使用 wikilink 格式**：`[[概念名]]`
3. **新建笔记时先搜索已有笔记**，避免重复
4. **同一条知识只写一次**，用链接引用

## ⚡ 工作流程

1. **捕获** → 所有内容先放入 `00_Inbox/`
2. **整理** → 定期将 Inbox 内容移到正确位置
3. **链接** → 确保新笔记链接到已有知识
4. **回顾** → 定期浏览 `index.md` 和图视图
