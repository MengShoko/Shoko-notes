## 🔗 两种笔记的关系

```
┌─────────────────────────────────────────────────────┐
│                    10_Courses/                       │
│  课程教材笔记：内容详细、系统性                         │
│  → 可引用 Zettelkasten 中的知识点                     │
│  → 各课程之间关联较少                                  │
└──────────────────────┬──────────────────────────────┘
                       │ 引用
                       ▼
┌─────────────────────────────────────────────────────┐
│                  Zettelkasten/                      │
│  知识点：原子化、精炼、可复用                           │
│  → 形成强大的知识网络（每个笔记 ≥2 个链接）              │
│  → 跨课程共享同一知识点                                │
└─────────────────────────────────────────────────────┘
```

**示例：**
- 你在「机器学习基础」课上学到「过拟合」→ 在 `10_Courses/机器学习基础/` 写详细课堂笔记
- 同时创建 `Zettelkasten/概念/过拟合.md` 作为原子知识点
- 课程笔记中用 `[[过拟合]]` 链接到知识点笔记
- 以后其他课程也学到「过拟合」时，直接链接到同一个知识点

## ⚡ 工作流程

### 日常学习
1. **捕获** → 课堂/阅读中的内容先放入 `00_Inbox/`
2. **分类** → 判断是课程笔记还是知识点
3. **整理** → 移动到正确位置，添加 frontmatter 和链接
4. **链接** → 课程笔记引用知识点，知识点互相连接

### 知识点维护
- 每个知识点笔记至少 **2 个 wikilink**
- 定期查看 `Zettelkasten/索引.md`
- 新学到的概念先搜索是否已有对应笔记
